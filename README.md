# 🎭 Rhythm Odyssey: Many in the One

**IB Dance Matrix Simulation — Interactive Performing Arts Activity**

An immersive, web-based interactive experience exploring Indian classical and folk dance traditions through the lens of the IB curriculum's "Unity in Diversity" theme.

## ✨ Features

### 🧘 Phase 1: The Rhythm Lab
- **Mudra AR Spatial Sensor** — Interactive hand gesture recognition (Pataka, Tripataka, Mayura)
- **Navarasa Emotional Resonance** — 9 classical expressions with authentic Bharatanatyam portrait cards
- **9-Rasa Mandala Matrix** — Full reference chart with definitions from Natyashastra

### 🌏 Phase 2: Regional Quest
- **8 Regional Dance Forms** — Bharatanatyam, Kathak, Bhangra, Garba, Bihu, Lavani, Chhau, Cheraw
- **Video Performances** — Authentic dance form demonstrations
- **Web Audio Solkattu Beats** — Rhythmic syllable patterns with real-time audio synthesis

### 🎼 Phase 3: Antigravity Fusion Symphony
- **3-Layer Audio Mixer** — Tabla, Flute, and Ghungroo layers
- **Master Tempo Control** — Real-time BPM adjustment
- **Golden Freeze Synthesis** — Synchronized 3-second silence ritual

### 📋 Phase 4: Assessment & Reflection
- **Rubric Scorecard** — Facilitator grading with IB criteria
- **Socratic Debrief** — Guided reflection prompts for deeper understanding

### 🚀 Interactive Coach HUD
- **5-Mission Guided Walkthrough** — Step-by-step interactive tour with live action detection
- **Real-time Feedback** — Audio chimes and spotlight focus on target elements

### 🌓 Theme System
- **Light & Dark Mode** — Full theme toggling with high-contrast text and localStorage persistence

## 🛠️ Tech Stack
- Pure **HTML5**, **CSS3**, **JavaScript** (no frameworks)
- **Web Audio API** for real-time sound synthesis
- **CSS Custom Properties** for theming
- **Responsive design** with glassmorphism aesthetics
